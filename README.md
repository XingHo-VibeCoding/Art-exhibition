## 一、这是什么

一个 **2:3 竖版**的线上作品展。

**纯 HTML + CSS + 原生 JS —— 零构建、零外部依赖。** 没有 `npm install`，没有打包步骤，
没有任何 CDN 请求，字体走系统字体栈。断网也能看。

当前阶段：**S1 展示系统 v5** —— 展陈骨架（装裱 / 铭牌 / 网格）已成形，
显影语法已换成「刷子刷出」；**环境色随作品尚未接入**。

## 二、怎么跑起来（两条路，任选）

### 路线 A · 直接双击（最快）

双击 `mvp/index.html`。

- 适合：随手看一眼、改完立刻刷新。
- 代价：地址栏是 `file:///...`，**不是** `localhost`。

### 路线 B · 起本地服务器（要交的那张截图走这条）

在**项目根目录**执行下面任一条：

```bash
# 方式 1 · Python（本机已装，无需额外安装）
python -m http.server 8080 --bind 127.0.0.1

# 方式 2 · Node（本机已装）
npx --yes http-server -p 8080 -a 127.0.0.1
```

然后在浏览器打开：

```
http://127.0.0.1:8080/mvp/
```

- 地址栏会显示 `127.0.0.1:8080` 开头的地址 —— 这就是「图里要有 localhost 地址栏」那张。
- **停止服务器**：回到那个终端窗口按 `Ctrl + C`。
- 若提示 `python` 找不到，用方式 2（Node）。

> 端口 8080 被占用时，把命令里的 `8080` 换成 8081 等，地址栏同步改。

## 三、怎么确认它真的在工作

1. 打开后先看到**揭幕**：两道墨色色块向中线合拢，站名从中缝显影。
   任意点击 / 按键 / 滚动 → 立即跳过。
2. 落到 **ARCANA** 系列（默认落在第一个有作品的主题）。
   应看到 **4 张塔罗牌**，每张都是「外框 → 卡纸 → 作品」三层，作品**完整不裁切**，
   下方三行铭牌：作品名（大）/ 系列名 / 编号。
3. 点任意一张 → **聚焦视图**打开，右侧三行信息齐全，后景虚化成墙。
4. 按 `←` `→` 换一张 —— 换印应当是**刷子从左到右刷出**（一道带毛边的软边推进），
   而不是滑动、淡入或重影。**这是 v5 的显影语法，也是这一步的验收点。**
5. 按 `Esc` 或点 `CLOSE` 关闭，回到原来的滚动位置。
