## 三、★ 本日最关键的发现：检查台的「提醒页门槛」

**这不是故障，是一条必须知道的门槛，也是同伴验收卡住的头号原因。**

### 实测事实（同一条 URL，只换请求头）

| 请求特征 | 返回 |
|---|---|
| 裸请求（无 UA、无导航头） | **200** + 真实页面（22823B） |
| 仅带 UA | **200** + 真实页面 |
| **完整导航头**（`Sec-Fetch-Mode: navigate` + `Sec-Fetch-Dest: document` + Accept + UA） | **404** + 提醒页（18127B，标题「风险提醒」） |

### 提醒页内容（真实浏览器实测）

> 页面访问提示
> 当前域名 `...tcloudbaseapp.com` 是由腾讯云 CloudBase 提供的**测试域名，仅供开发测试使用**……
> 页面路径：/checkup.html
> 当前访问量已达上限，如需继续访问，请联系……
> ［**确定访问**］

### 点击「确定访问」之后（真实浏览器 CDP 实测）

```
① 首跳标题 = 风险提醒
② 点击按钮 = BUTTON.redirect-page__operate-submit
③ 点击后标题 = Art Exhibition — Console     ← 真进去了
④ 网络请求：
     GET /checkup.html        200
     GET .../api/health       200
     GET .../api/works        200
⑤ 页面渲染：ONLINE · RTT 681ms · 四厅真实数据（29/22/15/19）
⑥ 控制台错误 = 无    未捕获异常 = 无
```

**截图证据**：`_ref/day21-out/live-checkup-entered.png`（点进去后的真实控制台）

### 结论与判断

1. **网站没挂**。门槛是 CloudBase **默认测试域名**的固有机制，与代码、配置、环境都无关。
2. **访客要多点一下**。这不是致命的（点一次即进），但对「同伴独立验证」是**实打实的摩擦** —— 同伴很可能看到「404 / 风险提醒」就回报「打不开」。
3. **根治办法**：绑定自定义域名（契约记忆里已记：`https://docs.cloudbase.net/service/alias`）。这是**下周（第 4 周）的优先项**。
4. **本次招呼话术**：请同伴**先点「确定访问」**，再判断能否打开。
