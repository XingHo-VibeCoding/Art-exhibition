### 第 0 步（重要，先做这一步）

打开下面的链接后，**如果先跳出一个「页面访问提示 / 风险提醒」的页面**——
那是腾讯云测试域名的提示页，**不是坏了**。

👉 **请点一下页面上的「确定访问」按钮**，然后才会进入真正的页面。

（这条坑我自己踩过，所以特意提醒你。）

### 第 1 步 · 打开链接

```
https://art-exhibition-d7ggtul83d566a6c9-1499147979.tcloudbaseapp.com/checkup.html
```

**期望看到**：深墨绿色页面，标题是 `ART EXHIBITION / LIVE CONSOLE`，
下面有三块：`SERVICE HEALTH`、`GALLERY DATA`、`WRITE TEST`。

### 第 2 步 · 做一次真实写入

1. 滚到最下面的 **`WRITE TEST`** 面板
2. 下拉框里随便选一幅作品（保持默认也行）
3. 点一下橙色的 **[TOGGLE LIKE]** 按钮
4. **看它下面出的那行字**

**期望看到**：出现类似
```
+1 LIKED   workId theology-01-0x0
likes = 6 ｜ liked = true ｜ xxx ms
```
（再点一次会变成 `−1 UNLIKED`，数字跟着回退——这是设计如此，叫「可取消的点赞」。）

### 第 3 步 · 看有没有报错

**按 F12**（手机可跳过这步），看 **Console** 页签有没有**红色的报错**。
另外刷新一下页面（F5），看数据是否还在、有没有变白屏。
